咪咪面板隐私政策（Android 版）

更新日期：2026 年 11 月 13 日 生效日期：2026 年 11 月 13 日 政策版本：第 5 版

咪咪面板（以下简称“本应用”）由开发者张世博（以下简称“我们”）提供。本应用是一个本地运行的管理面板，用于连接并管理您自行部署、与 mihomo 兼容的代理内核所提供的外部控制器（external-controller）接口。我们非常重视您的个人信息保护，请您在使用本应用前仔细阅读本政策。本政策文末附有《个人信息收集清单》《第三方共享清单》与《应用权限说明》三个附件，与正文具有同等效力。

一、我们不收集您的个人信息

  • 本应用不提供账号注册与登录，不需要您提供手机号、邮箱等身份信息。
  • 本应用不收集、不上传任何个人信息、设备标识符、使用统计或行为数据，没有自建服务器，不进行任何形式的数据分析或广告追踪。
  • 本应用未集成任何第三方 SDK（包括统计、广告、推送、崩溃上报等 SDK）。
  • 本应用运行所需的数据处理均在您的设备本地完成，或在本应用与您自己配置的后端之间进行；逐项明细见附件一。

二、本地存储的信息与保存期限

以下信息仅保存在您设备上本应用的存储空间中，不会被发送给我们：

  • 后端信息：您填写的名称、协议（HTTP/HTTPS）、地址、端口、路径前缀与访问密钥（secret）。这些信息保存在本应用的沙箱存储（系统 SharedPreferences）中，受 Android 系统沙箱隔离保护，其他应用无法访问；访问密钥在该存储中以明文形式保存，本应用已关闭系统自动备份（allowBackup=false），不会被备份到云端。请您妥善保管设备与密钥，密钥一旦泄露，他人可能借此控制您的后端。
  • 应用设置：主题、主题色、界面语言、毛玻璃与光感效果、测速参数、日志级别、显示与保留数量等偏好，同样保存在本应用的沙箱存储中。
  • 壁纸图片的副本：仅当您设置壁纸时，保存在本应用的私有目录中。
  • 连接与日志数据：连接列表、实时与累计流量、内存占用、后端日志流等来自后端的数据仅在内存中显示和使用，不写入磁盘，断开连接或退出应用后即释放。
  • 数据导出：本应用仅支持导出日志文本（通过系统分享面板或“另存为”由您选择去向）；后端配置（含地址与密钥）不可导出。

保存期限：后端信息与应用设置保存至您在应用内删除、或卸载本应用时为止；壁纸副本保存至您移除壁纸或卸载时为止。例外是闪退日志在公共下载目录中的镜像，卸载不会自动删除，详见下文。

桌面小组件快照

如果您把本应用的桌面小组件添加到桌面，本应用会在本机另存一份快照（独立的 SharedPreferences 文件 widget_snapshot），内容包括：后端备注名、连接状态、累计上传与下载流量、内存占用、活跃连接数、当前模式、主策略组名称与当前节点名称，仅用于小组件在本机显示，不会发送到任何服务器。

闪退日志

应用发生未捕获异常时，本应用会在本地生成一份闪退日志，用于您自行排查问题。每份日志包含：记录时间、应用版本、设备厂商与型号、系统版本、应用二进制接口（ABI）、异常类名、线程名与完整异常堆栈。

  • 应用内部副本保存在本应用私有目录，仅保留最近 20 份，超出后最旧的自动删除。
  • 为便于在本应用无法打开时取出日志，同一份日志还会镜像复制一份到公共下载目录「Download/MimiPanel」；镜像同样只保留最近 20 份，超出自动删除。
  • 请注意：「Download/MimiPanel」位于公共存储，卸载本应用不会自动删除这些镜像文件；如需删除，请在系统文件管理中打开「下载/MimiPanel」文件夹手动删除。该目录可被本机其他具有存储访问权限的应用读取，如您要对外分享日志，建议先自行检查内容。
  • 闪退日志不会自动上传到任何服务器。只有在您主动点击“复制”“分享”或“另存为”时，日志才会按您的选择交给剪贴板、您选定的应用或您选定的保存位置。

三、网络访问

除下文所列情形外，本应用的网络请求只发往您自己配置的后端地址，用于读取和修改代理内核的状态、配置、连接、日志与规则：

  • 节点延迟测试由您的后端执行：本应用只把您设置的测速地址（默认 https://connect.rom.miui.com/generate_204）作为参数发送给后端，本应用自身不访问该地址。
  • 图标加载：代理组详情中显示的图标，其网址来自后端返回数据中的 icon 字段，可以是任意远程网址，本应用会按该网址加载图片。提供该图标的服务器将因此获知您的设备 IP 地址与请求时间。如不希望产生此类请求，请不要在后端配置中为代理组设置图标。
  • 检查更新（因分发渠道而异）：
    • GitHub 渠道版本：仅在您点击“设置 → 关于 → 版本”时，本应用会访问 GitHub（api.github.com）查询本项目最新发布的版本号；若有新版本且您选择“去更新”，会用系统浏览器打开 GitHub 发布页。该请求不携带任何个人信息或设备标识，GitHub 可能按其自身隐私政策记录您的 IP 地址等访问信息。
    • 华为应用市场渠道版本：本应用不访问 GitHub；点击检查更新会直接拉起华为应用市场中本应用的详情页，版本更新由应用市场完成。
  • 桌面小组件联网：如果您添加了本应用的桌面小组件，点击小组件上的模式按钮（规则 / 全局 / 直连）时，小组件进程会直接读取本应用已保存的后端地址与访问密钥，向您自己的后端发送模式切换请求（PATCH /configs），以便在本应用未打开时也能切换模式。除此之外，小组件不访问任何其他服务器。
  • 除上述情形外，本应用不会向我们或其他任何服务器发送数据。

四、设备能力与权限

  • 重力传感器：仅在您开启“沉浸光感 → 跟随重力感应”时使用，用于调整界面高光方向，数据只在内存中实时使用，不保存、不上传。该功能默认关闭，应用退到后台时自动停止。
  • 图片选择：设置壁纸时通过系统照片选择器（Photo Picker）由您挑选一张图片，本应用只能访问您选定的那一张，不需要存储权限。
  • 文件保存与分享：通过系统“另存为”文件选择器（存储访问框架）与系统分享面板完成，只处理您主动导出的日志内容。
  • 剪贴板：仅在您点击“复制”时写入内容，本应用不读取剪贴板。
  • 本应用申请的系统权限及其用途见附件三。

五、您的权利

您可以随时在应用内查看、修改或删除您保存的后端与设置；可以在“设置 → 关于 → 撤回隐私政策同意”中撤回同意，撤回后应用将退出，下次启动时需要重新同意才能使用。您可以删除内部的闪退日志（设置 → 闪退日志），公共下载目录中的日志镜像请按第二节所述在文件管理中手动删除。卸载本应用会删除本应用沙箱与私有目录中的全部数据（下载目录中的日志镜像除外）。如需就您的个人信息行使其他法定权利，可通过第八节的邮箱联系我们。

六、未成年人保护

本应用面向具有代理内核部署与管理能力的用户，不主动面向未成年人提供服务，也不收集任何未成年人的个人信息。

七、政策更新

如本政策发生变更，我们会在应用内及本页面更新本政策并提高政策版本号；变更后您下次启动本应用时，我们会重新征求您的同意，您不同意可以停止使用并卸载本应用。
